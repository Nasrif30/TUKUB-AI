# TUKUB AI - Autonomous Security Agent

## Description
TUKUB AI is a terminal-based autonomous security agent for professional red team and blue team operations. Named after the Tausug word "tukub" meaning "to fight/attack like animals over territory."

## Features
- **ReAct Loop**: Observe -> Think -> Act pattern
- **50+ Security Tools**: Nmap, Nuclei, FFUF, SQLMap, BloodHound, etc.
- **Multi-LLM Support**: Ollama, Groq, OpenRouter, NVIDIA, HuggingFace, OpenAI, Anthropic
- **Jailbreak System**: 8 methods for authorized testing
- **Skill Management**: Zero context waste, auto-loads relevant skills
- **MCP Server**: Model Context Protocol support- **CTF Mode**: Flag detection and extraction
- **Red Team & Blue Team Modes**
